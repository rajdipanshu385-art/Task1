Task 1 – Data Cleaning & Preprocessing Using Excel
Project Overview
This project focuses on cleaning and preprocessing a dataset using Microsoft Excel. The objective is to identify and correct common data quality issues and prepare the dataset for further analysis.
Tool Used
•	Microsoft Excel
Dataset
The dataset was cleaned and processed using Excel.
Data Cleaning Steps Performed
The following cleaning operations were performed:
1.	Removed duplicate records.
2.	Identified and handled missing values.
3.	Cleaned missing Email, Gender, and Quantity values.
4.	Standardized Gender values into Male and Female.
5.	Standardized the Country field to India.
6.	Standardized date formats to DD-MM-YYYY.
7.	Organized the cleaned data into an Excel table.
8.	Compared the raw data with the cleaned data to verify the changes.
Workbook Structure
The Excel workbook contains the following sheets:
•	Raw_Data – Original dataset before cleaning.
•	Cleaned_Data – Final cleaned and standardized dataset.
•	Summary – Summary of the cleaning results.
•	Cleaning_Log – Record of the cleaning operations performed.
Conclusion
The dataset was successfully cleaned and standardized using Microsoft Excel. The cleaned dataset is now more consistent, organized, and suitable for further data analysis.
